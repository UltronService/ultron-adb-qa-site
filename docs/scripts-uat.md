# 測試劇本 UAT

## 路徑

`/scripts`（導覽列 **劇本**）

## 前置

- Agent 運行中（本地或辦公室）
- 至少一台 STB 已連線（試跑用）

## 步驟

| # | 操作 | 預期 |
|---|------|------|
| 1 | 開 `/scripts` | 看到兩個預載劇本（冷啟動、基本導航） |
| 2 | 左側點 **+ 等待** | 中間流程多一個步驟 |
| 3 | 拖曳 ⋮⋮ 調整順序 | 步驟編號跟著變 |
| 4 | 點步驟 → 右側改「等待秒數」 | 步驟名稱同步更新 |
| 5 | **儲存劇本** | 顯示「劇本已儲存」 |
| 6 | 選 STB → **試跑** | 下方逐步顯示 pass / fail |
| 7 | 重新整理頁面 | 劇本與步驟仍在 |

## 辦公室真機

試跑若顯示 mock 訊息 → Agent 未連 adb；STB online 後應顯示「已啟動」「已截圖」等真實結果。
